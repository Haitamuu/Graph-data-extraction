# FUNCTIONAL SPECIFICATIONS & TECHNICAL REQUIREMENTS
# ==============================================================================
#
# 1. 100% FULLY AUTOMATED PROCESSING (ZERO MANUAL INTERVENTION)
#    - End-to-end execution without manual coordinate picking or user inputs.
#    - No hardcoded axis coordinates, boundaries, or plot regions.
#    - Automatic batch processing of all figures in the images/ directory into data/.
#
# 2. AXIS CALIBRATION (OCR & ROBUST RANSAC REGRESSION)
#    - Automatic numeric tick label localization on X and Y axes via EasyOCR.
#    - Dual-pass OCR (Otsu binarized + grayscale fallback) ensuring thin and low-contrast numbers are parsed.
#    - Tick alignment validation and outlier rejection via linear RANSAC consensus with regular step verification.
#    - Automatic affine mapping: pixel coordinates -> real physical calibrated units.
#    - Safe fallback to pixel coordinates if an axis cannot be resolved.
#
# 3. LEGEND EXTRACTION & COLOR MATCHING
#    - Automatic text label localization for legends inside the plot.
#    - Detection of color patches and marker line segments located directly to the left of labels.
#    - Greedy bipartite matching between patches and extracted curves via minimum Euclidean RGB distance (threshold <= 70).
#    - Deterministic curve naming based on matched legend, or descriptive fallback (Curve_<Color> / Figure Title).
#
# 4. MULTI-CURVE SEGMENTATION (CHROMATIC & ACHROMATIC)
#    - Unsupervised chromatic clustering using MeanShift on cyclic HSV hue space (cos/sin representation).
#    - Subtractive morphological extraction for black/dark traces: filtering axes, grid lines, text labels,
#      and anti-aliasing artifacts from adjacent colored curves.
#    - Dynamic Y-axis lower-bound cutoff based on calibrated tick minimum to prevent false spikes from sub-axis ticks.
#
# 5. THEORETICAL MODEL vs. EXPERIMENTAL MEASUREMENTS DECOUPLING
#    - Autonomous trace taxonomy identification:
#        a) Pure experimental scatter plots (discrete points).
#        b) Pure continuous curves (smooth model/fitting).
#        c) Mixed curves: continuous fitting line + discrete experimental markers.
#    - For mixed curves:
#        * Exhaustive marker detection:
#          - Extraction of disconnected experimental points (including reaction onset at Y = 0).
#          - Guided template matching via normalized cross-correlation (NCC) along the trace.
#        * Decoupled continuous curve reconstruction:
#          - Local marker footprint subtraction avoiding curve skewing toward marker centers.
#          - Adaptive Savitzky-Golay filtering strictly preserving physical bounds (Y in [0, 1]) without ringing.
#
# 6. EXCEL OUTPUT SPECIFICATION (ADJACENT X AND Y COLUMNS)
#    - Generated output: data/<image_name>_data.xlsx
#    - For each extracted curve, the X-axis column is strictly adjacent to its corresponding Y-axis column:
#        * Mixed curve: <Name>_Line_X, <Name>_Line_Y, <Name>_Points_X, <Name>_Points_Y
#        * Simple curve: <Name>_X, <Name>_Y
#    - Calibrated real-unit coordinates without orphan columns.
#
# 7. VISUAL VERIFICATION COMPARISON PLOT
#    - Generated output: data/<image_name>_verification.png
#    - Side-by-side rendering:
#        * Left panel: Original scanned figure.
#        * Right panel: Reconstructed data overlay (solid line for continuous model, distinct scatter markers
#          preserving original color scheme).
#
# 8. ROBUSTNESS & WINDOWS / ONEDRIVE COMPATIBILITY
#    - Synchronization lock tolerance for Windows/OneDrive through automated retry logic.
#    - Clean, documented, modular Python 3 code.
